# 项目开发规范

## Python

- Python 3.11
- 使用 uv 管理依赖
- 不使用 pip 直接修改依赖
- 使用类型注解
- async 函数不要改成同步函数

## 项目

- FastAPI 作为 Web 框架
- LangGraph 负责 Agent 工作流
- Milvus 用于向量检索
- MongoDB 用于业务数据
- BGE-M3 用于 embedding

## 修改原则

1. 优先最小修改
2. 不随意重构已有模块
3. 不修改函数接口，除非明确要求
4. 修改前先分析调用链
5. 不删除已有异常处理
6. 不修改 .env
7. 不把密钥写入代码
